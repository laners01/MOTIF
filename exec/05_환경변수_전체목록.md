# MOTIF 환경변수 전체 목록

기준일: 2026-09-28. 운영 클러스터 실측(키 수)과 레포 매니페스트 기준이며, **값은 어디에도 적지 않는다**(레포 커밋 금지). 백엔드는 k8s Secret 7개 + ConfigMap 1개, AI 는 GCP Secret Manager 3개 + Cloud Run env, 앱은 로컬 파일 2개로 구성된다.

| 위치 | 소비 주체 | 관리 방법 |
|---|---|---|
| k8s Secret `postgres-secret` `rabbitmq-secret` `redis-secret` | PostgreSQL · RabbitMQ · Redis 파드 | 서버에서 `kubectl create secret generic` (예시 `infra/k8s/*/secret.example.yaml.txt`) |
| k8s Secret `core-api-secret` + ConfigMap `core-api-config` | core-api | 동일. AWS 키·PEM·토큰·해시는 `kubectl patch`. 변경 후 `rollout restart` |
| k8s Secret `app-media-secret` | app-media | 동일 |
| k8s Secret `app-notification-secret` + `app-notification-fcm`(파일) | app-notification | 동일. FCM 은 `--from-file=service-account.json=…` |
| Deployment `env` (매니페스트 고정값) | 세 앱 · postgres · rabbitmq · redis | 레포 `infra/k8s/*/deployment.yaml` |
| `application*.yml` 기본값 | 세 앱 | 레포. 운영에서 별도 주입하지 않는 값 |
| GCP Secret Manager + Cloud Run Job/Service env | AI 접수 서비스 · GPU Job | `gcloud run jobs/services … --set-secrets/--set-env-vars` |
| `android/local.properties` + `android/app/google-services.json` + `strings.xml` | 안드로이드 빌드 | 개발자 로컬(gitignore) |
| `backend/.env` (`.env.example` 복사) | 로컬 하이브리드 모드 | 개발자 로컬 |
| Jenkins credentials · 호스트 설정 파일 | CI/CD | Jenkins 관리 화면 · `/etc/systemd/…`, `/var/lib/jenkins/…` |

"필수" 는 미주입 시 기동 실패(또는 해당 기능 전면 실패)를 뜻한다.

## 1. PostgreSQL (`postgres-secret` 3개 + Deployment env)

| 키 | 용도 |
|---|---|
| `POSTGRES_PASSWORD` | superuser `postgres` 비밀번호. 필수 |
| `CORE_APP_PASSWORD` | init.sh 가 만드는 `core_app` 계정 비밀번호. core-api·app-media 의 `DB_PASSWORD` 와 같은 값. 작은따옴표 금지 |
| `NOTIF_APP_PASSWORD` | `notif_app` 계정 비밀번호. app-notification 의 `DB_PASSWORD` 와 같은 값 |

Deployment 고정값: `POSTGRES_DB=motif`, `POSTGRES_USER=postgres`, `PGDATA=/var/lib/postgresql/data/pgdata`. 세 비밀번호는 서로 달라야 한다(계정 격리). init.sh 는 PVC 가 비어 있을 때만 실행되므로 비밀번호 변경은 `ALTER ROLE` 로 한다.

## 2. RabbitMQ (`rabbitmq-secret` 5개 + Deployment env)

| 키 | 용도 |
|---|---|
| `RABBITMQ_ADMIN_PASSWORD` | 관리 UI `admin`(administrator) 계정 |
| `RABBITMQ_CORE_PASSWORD` | 계정 `core-api` — core-api 의 `MQ_PASSWORD` 와 같은 값 |
| `RABBITMQ_NOTIF_PASSWORD` | 계정 `notification` — app-notification 의 `MQ_PASSWORD` 와 같은 값 |
| `RABBITMQ_MEDIA_PASSWORD` | 계정 `media` — app-media 의 `MQ_PASSWORD` 와 같은 값. **없으면 postStart 훅이 죽어 파드가 안 뜬다** |
| `RABBITMQ_GPU_PASSWORD` | 계정 `gpu-worker` (테일넷 5672 접속, 레거시 큐 경로. 현재 AI 는 HTTP 접수라 미사용) |

Deployment 고정값: `TZ=Asia/Seoul`, `RABBITMQ_DEFAULT_VHOST=/motif`. 계정·권한은 postStart 훅이 `rabbitmqctl` 로 만든다(definitions 에는 없음).

## 4. core-api (`core-api-secret` 12개 + `core-api-config` 2개 + Deployment env)

| 키 | 용도 |
|---|---|
| `DB_PASSWORD` | `core_app` 비밀번호 (= `CORE_APP_PASSWORD`). 필수 |
| `MQ_PASSWORD` | RabbitMQ `core-api` 계정 (= `RABBITMQ_CORE_PASSWORD`). 필수 |
| `REDIS_PASSWORD` | = redis-secret 값. 필수 |
| `JWT_SECRET` | 팬 앱 access/refresh JWT HS256 서명키. **32자 이상**(`openssl rand -hex 32`). 회전 = 전원 로그아웃. 필수 |
| `ADMIN_JWT_SECRET` | 어드민 JWT 서명키. **`JWT_SECRET` 과 다른 값**, 32자 이상. 필수 |
| `GOOGLE_CLIENT_ID` | Google OAuth **웹 애플리케이션** 클라이언트 ID(`aud` 검증). 앱 `google_web_client_id` 와 동일. 필수 |
| `AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY` | IAM 사용자 `motif-core-api` 키(S3 presign·HEAD, CloudFront 아님). 서버 IMDS 역할을 이기려면 반드시 주입 |
| `CLOUDFRONT_PRIVATE_KEY` | CloudFront 서명용 RSA 2048 개인키, PKCS#8 PEM 전체(base64 patch 로 주입, 길이 1704). 비면 보호 영상 URL 발급만 500 |
| `MOTIF_WORKER_TOKEN` | AI 접수·콜백 공유 비밀(`X-Motif-Worker-Token`, 64자). GCP Secret Manager `motif-worker-token` 과 같은 값. 비면 콜백 전부 401 |
| `ADMIN_SEED_HASH` | 어드민 계정 `admin` 비밀번호 BCrypt(cost 10) 해시(생성 명령은 표 아래). Liquibase 시드(0015)가 읽는다. 필수 |
| `TOSS_SECRET_KEY` | 토스페이먼츠 시크릿 키(현재 `test_sk_…`). 비면 결제 승인만 500 |

```bash
htpasswd -bnBC 10 "" '평문' | tr -d ':\n'
```

## 7. AI 파이프라인 (GCP Cloud Run)

### 7.1 GPU Job (`motif-compose-job`, `motif-precompute-job`)

| 키 | 정의 위치 | 용도 |
|---|---|---|
| `MOTIF_WORKER_TOKEN` | Secret Manager `motif-worker-token` | 콜백 헤더 `X-Motif-Worker-Token`. 백엔드 `core-api-secret` 의 값과 동일. 필수 |

| `AWS_REGION` | Job env | `ap-northeast-2` |
| `S3_BUCKET` | Job env | `motif-media`. 필수 |
| `PRECOMPUTED_PREFIX` | Job env | 사전분석 키 prefix `precomputed`(두 Job 동일해야 함) |
| `MODEL_BUNDLE_VERSION` | Job env(선택) | 모델 번들 지문. 기본 `models-v1`. 사전분석과 합성이 불일치하면 합성 실패 |
| `MOTIF_SKIP_FINGERPRINT` | Job env | `1` 이면 코드·가중치 지문 게이트 우회. **현재 compose-job 에 설정된 테스트 플래그** |

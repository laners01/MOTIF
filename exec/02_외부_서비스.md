# MOTIF 외부 서비스 정리

프로젝트가 의존하는, 외부 가입·키 발급이 필요한 서비스는 아래 9개다. PostgreSQL·RabbitMQ·Redis·Jenkins·k3s 는 전부 self-hosted 로 외부 가입이 필요 없다. 값(키·비밀번호)은 어디에도 적지 않는다.

## 1. Google 로그인 (Google Identity)

| 항목 | 내용 |
|---|---|
| 콘솔 | https://console.cloud.google.com → API 및 서비스 → 사용자 인증 정보 |
| 용도 | 소셜 로그인. 앱이 Credential Manager 로 받은 Google ID 토큰을 서버가 검증하고 회원을 자동 생성한다 |
| 발급 필요 | OAuth 2.0 **웹 애플리케이션** 클라이언트 ID 1개 (`GOOGLE_CLIENT_ID`). 안드로이드는 이 웹 ID 를 `serverClientId` 로 쓴다 |
| 콘솔 설정 | 같은 프로젝트에 Android 클라이언트(패키지 `com.ssafy.motif` + 디버그·릴리스 SHA-1) 등록. 로그인 테스트 페이지를 쓰려면 승인된 JavaScript 원본에 `https://j15d104.p.ssafy.io` |
| 서버 검증 | `spring-security-oauth2-jose` 가 `https://www.googleapis.com/oauth2/v3/certs`(JWKS) 로 서명·`aud` 를 검증. 실패 코드 `INVALID_GOOGLE_TOKEN` |
| 앱 설정 | `android/feature/signin/impl/src/main/res/values/strings.xml` 의 `google_web_client_id` (서버 값과 동일해야 함) |

## 2. Firebase (FCM 푸시 알림)

| 항목 | 내용 |
|---|---|
| 콘솔 | https://console.firebase.google.com |
| 용도 | 합성 완료·실패, 새 챌린지·공지·댓글·답글 푸시 발송 (app-notification 이 FCM HTTP v1 로 발송, data-only 메시지) |
| 발급 필요 | ① 서비스 계정 비공개 키 JSON (프로젝트 설정 → 서비스 계정 → 새 비공개 키) ② `google-services.json` (프로젝트 설정 → 내 앱 → Android `com.ssafy.motif`) |
| 배치 위치 | 서버: k8s Secret `app-notification-fcm` → 파드 `/etc/fcm/service-account.json`(read-only 0440). 앱: `android/app/google-services.json` (없으면 빌드 실패) |
| 특이사항 | 서비스 계정 키 하나로 전 사용자 푸시가 가능하므로 Secret 으로만 관리. 알림 목록 API 는 없고 앱이 로컬에 저장한다. Google 로그인과 같은 GCP 프로젝트를 써도 되고 달라도 된다(앱 `google-services.json` 은 Firebase 프로젝트 기준) |

## 3. AWS S3 (미디어 원본·산출물 저장)

| 항목 | 내용 |
|---|---|
| 콘솔 | https://console.aws.amazon.com/s3 · IAM |
| 용도 | 촬영본 업로드(앱 → presigned PUT 직행), 챌린지 원본·편집본·에셋·프로필·공지 이미지, app-media 가 만든 HLS·썸네일, AI 결과·사전분석 산출물 |
| 버킷 | `motif-media`, 리전 `ap-northeast-2`. 프리픽스: `raw/`(촬영본, 7일 후 삭제 가능), `challenges/`, `assets/`, `profiles/`, `artists/`, `notices/`, `private/challenge·motif/{jobUuid}/`(보호 HLS), `private/edited/{챌린지}/{슬롯}/`(편집본), `results/`(AI 결과), `precomputed/`(사전분석), `dev/`(로컬 개발) |
| 발급 필요 | IAM 사용자 3개의 액세스 키: `motif-core-api`(PutObject·GetObject·ListBucket), `motif-app-media`(GetObject·PutObject·ListBucket), `motif-gpu-worker`(GET `raw/* private/edited/* challenges/* assets/* precomputed/*`, PUT `results/* precomputed/*`) |
| 관련 변수 | `AWS_ACCESS_KEY_ID`/`AWS_SECRET_ACCESS_KEY`(core-api-secret, app-media-secret, GCP Secret Manager), `MOTIF_MEDIA_BUCKET`, `AWS_REGION`, `S3_BUCKET` |
| 특이사항 | **버킷은 팀이 아닌 개인 프리티어 AWS 계정**에 있다(`infra/setup/video-poc-cdn.md`). 서버 IMDS 가 SSAFY 계정 역할을 흘리므로 env 키를 반드시 주입해야 한다. 이관 시 버킷 복제 + IAM 재생성 + CloudFront 오리진 변경이 필요 |

## 4. AWS CloudFront (미디어 CDN · 서명 URL)

| 항목 | 내용 |
|---|---|
| 콘솔 | https://console.aws.amazon.com/cloudfront |
| 용도 | 앱이 재생·표시하는 모든 미디어 URL 의 호스트. 공개 등급(챌린지 원본·에셋·프로필·공지·배너)은 무서명, 보호 등급(`private/*`: 참여 영상 HLS·편집본·결과)은 **signed URL**(custom policy 프리픽스 서명: 재생목록 2h · 단일 영상 10m · 이미지 6h) |
| 배포 | `https://d21so2cpi8si9r.cloudfront.net` (`MOTIF_MEDIA_PUBLIC_BASE_URL` 기본값). 오리진 S3 `motif-media` + OAC, Behavior `private/*` = Restrict viewer access(키 그룹), Cache policy CachingOptimized, HTTP/2 |
| 발급 필요 | RSA 2048 키페어. `openssl genrsa -out cf_private.pem 2048` → 공개키를 Key management > Public keys 에 등록(ID 가 `CLOUDFRONT_KEY_PAIR_ID`, 현재 `K27QE85H6DLYDD`) → 키 그룹 |
| 관련 변수 | `MOTIF_MEDIA_PUBLIC_BASE_URL`, `CLOUDFRONT_KEY_PAIR_ID`, `CLOUDFRONT_PRIVATE_KEY`(PKCS#8 PEM, core-api-secret, base64 patch 로 주입) |
| 검증 | `curl https://d21so2cpi8si9r.cloudfront.net/private/motif/none/master.m3u8` → `MissingKey` 면 보호 설정 정상. 개인키가 비면 보호 URL 발급만 500 |

## 5. Google Cloud Platform (AI 합성 파이프라인)

| 항목 | 내용 |
|---|---|
| 콘솔 | https://console.cloud.google.com — 프로젝트 `ssafy-motif` |
| 용도 | GPU 합성·사전분석 실행 환경 전체. 백엔드 서버(SSAFY EC2)에는 GPU 가 없다 |
| 사용 서비스 | **Cloud Run Service** `motif-intake`(asia-southeast1, 접수 HTTP) · **Cloud Run Jobs + GPU** `motif-compose-job`·`motif-precompute-job`(us-central1, `nvidia-rtx-pro-6000`) · **Artifact Registry** `video-workers`(이미지) · **Cloud Build**(이미지·wheel 빌드, E2_HIGHCPU_32) · **Cloud Storage** `ssafy-motif-models-us`(모델 가중치 ~35GB, gcsfuse 마운트) · **Secret Manager**(워커 토큰·AWS 키) · **Cloud Logging**(실행 로그) |
| 발급 필요 | 프로젝트 결제 계정, GPU 쿼터(us-central1 RTX PRO 6000), API 활성(Run·Build·Artifact Registry·Secret Manager·Storage), 기본 compute 서비스 계정 권한(`storage.objectViewer`, `secretmanager.secretAccessor`, `run.developer`) |
| 관련 변수 | Job: `MOTIF_WORKER_TOKEN` `AWS_ACCESS_KEY_ID` `AWS_SECRET_ACCESS_KEY`(Secret Manager), `MOTIF_CALLBACK_BASE` `AWS_REGION` `S3_BUCKET` `PRECOMPUTED_PREFIX`. intake: `COMPOSE_JOB_RESOURCE` `PRECOMPUTE_JOB_RESOURCE`. 백엔드: `AI_SUBMIT_URL`(intake URL), `MOTIF_WORKER_TOKEN`(동일 값) |
| 과금 주의 | GPU Job 은 실행 중에만 과금(잡당 14~50분 × RTX PRO 6000 + 20 vCPU/80Gi). 콜드스타트마다 가중치 17.7GB gcsfuse 읽기, S3↔GCP 리전 간 이그레스(슬롯당 0.9~3.2GiB). Vertex AI 는 검토 후 미사용(H100 쿼터만 잔존, 미사용 시 과금 없음) |

## 6. 토스페이먼츠 (모티프 결제)

| 항목 | 내용 |
|---|---|
| 콘솔 | https://developers.tosspayments.com (개발자센터 → API 키) |
| 용도 | 모티프 에셋 개별 구매·모티프 패스 결제. 앱이 결제 위젯으로 승인 정보(paymentKey·orderId·amount)를 받고, 서버가 `POST /api/v1/orders/{orderUuid}/confirm` 에서 토스 승인 API 를 호출한다. 웹훅 없음 |
| 발급 필요 | 테스트 **클라이언트 키**(`test_ck_…`, 앱) + 테스트 **시크릿 키**(`test_sk_…`, 서버) 한 쌍 |
| 배치 위치 | 앱: `android/local.properties` 의 `TOSS_CLIENT_KEY` → `BuildConfig.TOSS_CLIENT_KEY`. 서버: `core-api-secret` 의 `TOSS_SECRET_KEY` |
| 특이사항 | 현재 **테스트 결제 환경**(실카드 결제 안 됨, 테스트 카드 사용). 라이브 전환 = 키 두 개 교체 + `rollout restart` + 앱 재빌드. 시크릿 키가 비면 서버는 뜨고 승인만 500 |

## 7. Tailscale (운영 접근망)

| 항목 | 내용 |
|---|---|
| 콘솔 | https://login.tailscale.com/admin |
| 용도 | 서버 노드(`motif-server`, 100.106.64.43)와 팀원 기기를 사설망으로 묶는다. 어드민(`/admin/**`) 허용 대역 `100.64.0.0/10`, PostgreSQL·RabbitMQ·Jenkins 노출, k3s flannel 인터페이스, 로컬 하이브리드 모드의 서버 MQ 접속 |
| 발급 필요 | 테일넷 계정 1개(팀 공유), 노드별 `tailscale up`. 콘솔에서 서버 노드 **Disable key expiry** |
| 특이사항 | 도메인 `j15d104.p.ssafy.io` 는 공인 IP 로 풀리므로 어드민을 보려면 hosts 에 `100.106.64.43 j15d104.p.ssafy.io` 를 넣는다. 끝나면 지운다(남으면 `/api/**` 도 테일넷을 탄다) |

| 항목 | 내용 |
|---|---|

| 용도 | `j15d104.p.ssafy.io` 인증서(`motif-tls`), 만료 30일 전 자동 갱신 |

| 특이사항 | prod 는 실패 주 5회 제한 → 설정 변경은 staging 으로 먼저. `kubectl get certificate motif-tls` 로 READY 확인 |

## 11. 환경 변수와의 매핑

| 키 | 위치 | 서비스 |
|---|---|---|
| `GOOGLE_CLIENT_ID` / `google_web_client_id` | core-api-secret / 앱 strings.xml | Google 로그인 |
| `service-account.json` / `google-services.json` | Secret `app-notification-fcm` / `android/app/` | Firebase FCM |
| `AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY` / `MOTIF_MEDIA_BUCKET` / `AWS_REGION` / `S3_BUCKET` | core-api-secret, app-media-secret, GCP Secret Manager + Job env | AWS S3 |
| `MOTIF_MEDIA_PUBLIC_BASE_URL` / `CLOUDFRONT_KEY_PAIR_ID` / `CLOUDFRONT_PRIVATE_KEY` | core-api (yml 기본값 · core-api-secret) | AWS CloudFront |
| `AI_SUBMIT_URL` / `MOTIF_WORKER_TOKEN` / `MOTIF_CALLBACK_BASE` / `COMPOSE_JOB_RESOURCE` / `PRECOMPUTE_JOB_RESOURCE` | core-api-config·core-api-secret / Cloud Run env·Secret Manager | GCP Cloud Run |
| `TOSS_SECRET_KEY` / `TOSS_CLIENT_KEY` | core-api-secret / `android/local.properties` | 토스페이먼츠 |
| `ADMIN_ALLOWED_CIDRS`(`100.64.0.0/10`) / `SERVER_MQ_HOST` | core-api-config / `backend/.env` | Tailscale |
| ClusterIssuer 이메일 | `infra/k8s/00-cert-manager/clusterissuer.yaml` | Let's Encrypt |
| Jenkins credentials `gitlab-pat` / `gitlab-api` / 웹훅 Secret Token | Jenkins 관리 화면 · GitLab Webhooks | GitLab |

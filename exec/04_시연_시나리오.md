# MOTIF 시연 시나리오

시연 순서에 따른 화면별·실행별(탭 위치) 상세 설명. 핵심 기능 4가지, 즉 ① 챌린지 참여(온디바이스 실시간 합성 + 서버 AI 합성) / ② 소셜(홈 피드·랭킹·구독·댓글) / ③ 모티프(유료 콘텐츠·토스 결제·보관함) / ④ 비동기 처리·FCM 알림을 실제 발표 시연 순서대로 배치했다.

- 표의 **실행** 열이 탭 위치·조작이고, **기대 결과**가 화면에서 확인할 내용이다.
- **멘트 포인트**는 해당 단계에서 발표자가 말하는 대본이다(부록에 전문).

## 시연 흐름 요약

```
로그인(구글) · 온보딩(아티스트 구독 → 닉네임)
→ 홈: 인기 챌린지 영상 → Who's On 랭킹 → 구독 아티스트 활동 피드
→ 챌린지 탭: 숏폼 탐색 · 좋아요 · 댓글 · 상세 · 참여 영상
→ 챌린지 촬영: 위치 선택 → 5초 카운트다운 → 실시간 합성 화면 보며 원테이크 촬영
→ 업로드 · 서버 AI 합성(비동기) → FCM 알림 → 결과 확인 → 소개글·공개 설정 → 게시
→ 마이페이지 → 아티스트 상세
→ 모티프 탭: Shop(개별 구매 · 패스) → 토스 테스트 결제 → 사용 가능 영상 → 보관함 · 대표 모티프
→ 모티프 촬영(구미 아티스트) → 보관함 저장 → 마무리
```

> 시연 팁: 서버 AI 합성은 챌린지 약 26~28분, 모티프 약 14분이 걸리고 접수까지 2~3분이 더 걸린다. 시연 중 완성을 기다릴 수 없으므로 **완료 알림·결과 확인 단계는 미리 돌려 둔 잡**으로 보여 준다. 촬영 → 업로드 → "AI가 영상을 만들고 있어요" 까지만 라이브로 하고, 알림은 사전에 완료된 잡의 결과로 이어 간다. AI 접수가 비활성인 서버에서는 운영 노드의 `demo_complete.py` 가 가장 최근 챌린지 잡을 완료 처리해 FCM 까지 정상 경로로 보낸다.

## 사전 준비 체크리스트

| 구분 | 항목 |
|---|---|
| 서버 | `kubectl get pods` 6개 Running, `curl https://j15d104.p.ssafy.io/api/health` = `{"status":"UP"}` |
| 서버 | 심사 전 Swagger 인그레스 블록 제거(`infra/k8s/40-core-api/ingress.yaml`), access 토큰 TTL 1h 로(`MOTIF_ACCESS_TOKEN_TTL`) |
| 서버 | 시연 데이터 등록 완료(어드민, 테일넷 접속): 소속사 → 그룹 → 아티스트 → 곡 → 챌린지(원본·슬롯 앵커·편집본) → 에셋 → 공지 → 배너. 시연할 챌린지 슬롯은 편집본 + AI 사전분석(`precomputed/{챌린지}/{슬롯}/ready.json`) 완료 |
| 서버 | 토스 테스트 시크릿 키(`TOSS_SECRET_KEY`) 주입, 결제 시연용 테스트 카드 준비 |
| 서버 | 알림 시연용으로 **미리 완료된 챌린지 잡 1개**(결과 영상 재생 가능) 준비. AI 접수가 꺼져 있으면 `python3 ~/demo_complete.py` 로 완료 처리 |
| 앱 | `google-services.json` + `local.properties`(`TOSS_CLIENT_KEY`) 로 빌드한 APK 설치 |
| 앱 | 카메라 권한 수동 허용: `adb shell pm grant com.ssafy.motif android.permission.CAMERA` (앱에 런타임 요청 코드 없음). 알림 권한은 첫 진입 팝업에서 허용 |
| 앱 | `DEMO_MODE`(MainActivity) 결정. `true` 면 로그인·온보딩은 화면만 진행되고 실제 API 는 기기에 저장된 세션 토큰을 쓴다 → 시연 기기에서 사전에 실제 구글 로그인을 1회 완료해 둔다. `false` 면 라이브 로그인 |
| 앱 | 시연 계정이 구미 아티스트를 구독 중이고, 결제 시연 전에는 해당 에셋을 **보유하지 않은 상태**(결제 후 "구매 완료" 전환을 보여 주기 위해) |
| 앱 | 보관함에 미리 완성된 모티프 영상 1개 이상(모티프 결과 확인·대표 모티프 설정용) |
| 네트워크 | 시연 기기는 공인망(테일넷 hosts 줄 없음). 서버 확인용 PC 는 테일넷 + hosts 줄로 어드민 접근 |

## 0. 로그인·온보딩

| # | 실행 | 기대 결과 |
|---|---|---|
| 0-1 | 앱 실행 → 로그인 화면(배경 영상)에서 **"Sign in with Google"** 탭 → 구글 계정 선택 | 서버가 ID 토큰을 검증하고 세션 발급. 기존 회원이면 홈, 최초면 온보딩 |
| 0-2 | (최초 로그인) 아티스트 선택 화면: 검색 또는 목록에서 관심 아티스트 1명 이상 선택 → 다음 | 선택 수가 "N명 선택" 으로 표시되고 구독으로 저장 |
| 0-3 | 닉네임 입력(2~20자) → 완료 | 홈 진입. Android 13 이상이면 알림 권한 팝업 → 허용 |

멘트 포인트: "MOTIF 는 구글 로그인을 통해 간편하게 로그인할 수 있습니다. 최초 로그인 시에는 앱을 시작하기 전에 관심 있는 아티스트를 한 명 이상 선택해 구독하고, 닉네임을 설정한 뒤 서비스에 진입하게 됩니다."

## 1. 홈 화면

| # | 실행 | 기대 결과 |
|---|---|---|
| 1-1 | 홈 상단 **인기 챌린지 영상** 캐러셀 확인 (카드 탭 → 참여 영상 피드 → 뒤로) | 사용자들이 참여한 챌린지 중 인기 영상이 가로 캐러셀로 표시 |
| 1-2 | 아래 **Who's On** 랭킹 확인 → **전체보기** 탭 | 아티스트별 인기 챌린지 랭킹. 전체보기에서 전체 랭킹(필터·검색) → 뒤로 |
| 1-3 | 아래로 스크롤 → **구독 아티스트 활동 피드** | 구독한 아티스트의 새 공지사항·새 모티프 영상이 하나의 피드로 표시. 공지 좋아요·댓글 가능 |

멘트 포인트: "홈 상단에서는 현재 사용자들이 참여한 챌린지 중 인기 있는 영상들을 바로 확인할 수 있습니다. 그 아래 Who's On 랭킹에서 아티스트별로 어떤 챌린지가 인기를 얻고 있는지 확인할 수 있고, 아래로 내려가면 구독한 아티스트들의 최신 활동을 하나의 피드로 볼 수 있습니다."

## 2. 챌린지 탭

| # | 실행 | 기대 결과 |
|---|---|---|
| 2-1 | 하단 **챌린지** 탭 → 세로 스와이프 | 아티스트 챌린지 원본 영상이 숏폼 형태로 재생·전환 |
| 2-2 | **좋아요** 탭, **댓글** 탭 → 댓글 작성·답글 | 좋아요 수 반영, 댓글 시트에 작성한 댓글 표시 |
| 2-3 | 챌린지 **상세(설명) 시트** 열기 | 아티스트·곡·설명·참여 아티스트(콜라보) 정보 |
| 2-4 | **참여 영상 보기** 탭 → 뒤로 | 이 챌린지에 참여한 다른 사용자들의 영상 피드 |
| 2-5 | 마음에 드는 챌린지에서 **촬영(카메라) 버튼** 탭 | 챌린지 촬영 화면 진입 |

멘트 포인트: "챌린지 탭에서는 아티스트들이 올린 챌린지 영상을 숏폼 형태로 탐색할 수 있습니다. 좋아요·댓글로 소통할 수 있고, 상세 정보와 함께 참여한 다른 사용자들의 영상도 확인할 수 있습니다. 마음에 드는 챌린지를 발견했다면 이 화면에서 바로 참여할 수 있습니다. 한번 직접 참여해보겠습니다."

## 3. 챌린지 촬영 (핵심 ①)

| # | 실행 | 기대 결과 |
|---|---|---|
| 3-1 | **위치 선택**: 챌린지 첫 장면 위의 슬롯 뱃지("Here!") 중 하나 탭 → **Start Challenge** | 선택한 슬롯의 아티스트가 지워진 편집본 미리보기로 전환. 편집본이 없는 슬롯은 잠김 |
| 3-2 | 촬영 시작 → **5초 카운트다운** | 카운트다운 중부터 후면 카메라의 내 모습이 인물만 분리(온디바이스 세그멘테이션)되어 아티스트 영상 위에 실시간으로 겹쳐 보임 → 위치·동작을 맞춘다 |
| 3-3 | 카운트다운 종료 | 아티스트 원본(편집본) 재생과 촬영이 동시에 시작. 상단 타이머 표시. 원본이 끝나면 자동 종료(원테이크). 필요 시 **Retry** |

멘트 포인트: "먼저 아티스트와 함께 촬영할 사용자의 위치를 선택합니다. 촬영을 시작하면 5초의 카운트다운이 진행되고, 이때부터 온디바이스에서 사용자의 영역을 실시간으로 분리해 아티스트 영상 위에 합성해주기 때문에 자신이 실제 영상 안에 들어가 있는 모습을 보면서 위치와 동작을 맞출 수 있습니다. 카운트다운이 끝나면 원본 영상과 촬영이 동시에 시작되고, 원본이 끝날 때까지 원테이크 방식으로 촬영됩니다."

## 4. 업로드·AI 합성 (핵심 ④, 비동기)

| # | 실행 | 기대 결과 |
|---|---|---|
| 4-1 | 촬영 종료 후 자동 진행 | "영상을 준비하고 있어요" → "영상을 업로드하고 있어요 N%"(S3 직접 업로드 진행률) → "AI 영상 제작을 요청하고 있어요" |
| 4-2 | 요청 완료 | "AI가 영상을 만들고 있어요 / 완성되는 동안 다른 챌린지를 둘러보세요 / 영상이 완성되면 알림으로 알려드릴게요" + **챌린지 둘러보기** 버튼 |
| 4-3 | **챌린지 둘러보기** 탭 → 다른 챌린지 탐색 | 합성이 백그라운드에서 진행되는 동안 앱의 다른 기능이 정상 동작 |
| 4-4 | (미리 완료해 둔 잡) **"MOTIF 알림"** 푸시 수신 → 알림 탭 | 완성된 영상의 결과 화면으로 바로 이동 |

멘트 포인트: "촬영이 끝나면 사용자 촬영 원본을 서버로 전달합니다. 서버에서는 앞서 설명드린 AI 기술을 활용해 색감과 조명, 춤 동작 등을 보정하고 최종 영상을 합성합니다. 합성은 비동기로 진행되며, 작업이 완료되면 FCM 알림을 통해 사용자에게 알려줍니다."

## 5. 결과 확인·업로드

| # | 실행 | 기대 결과 |
|---|---|---|
| 5-1 | 결과 화면에서 완성 영상 재생 | 아티스트 영상 안에 내가 합성된 결과(HLS) 재생. 하단 **업로드** / **삭제** |
| 5-2 | **업로드** 탭 → 소개글 입력, 전체 공개/비공개, 댓글 허용 선택 → 확인 | 참여 영상으로 게시 |
| 5-3 | 자동 이동 | 해당 챌린지의 참여 영상 피드, 내 영상이 첫 화면. 챌린지 참여 완료 |

멘트 포인트: "사용자는 완성된 영상을 확인한 뒤 간단한 소개글과 함께 공개·비공개 여부, 댓글 허용 여부를 설정해서 업로드할 수 있습니다. 업로드가 완료되면 최종적으로 챌린지 참여가 완료됩니다."

## 8. 모티프 탭 — Shop · 결제 · 보관함 (핵심 ③)

| 8-3 | **구매** 탭 → 토스페이먼츠 결제 화면 → 테스트 카드로 결제 | 결제 위젯(테스트 환경) → 승인 → "구매 완료" 상태로 즉시 전환, 촬영 진입 버튼 활성화 |
| 8-4 | (또는) 배너·아티스트 섹션에서 **Pass 구매** → 이용 기간(개월) 선택 → 결제 | 패스 보유 상태. 기간 동안 그 아티스트의 일반 모티프 영상 자유 사용 |
| 8-5 | 서브메뉴 **모티프** | 구매했거나 패스로 현재 사용할 수 있는 영상 목록(아티스트 필터) |
| 8-6 | 서브메뉴 **보관함** → 영상 재생 → **대표 모티프로 설정** | 지금까지 아티스트와 만든 모티프 영상 목록. 대표 설정 시 MY 상단에 반영 |

멘트 포인트: "모티프는 쉽게 말하면 인생네컷의 영상 버전입니다. 아티스트가 제공하는 짧은 영상 속에 사용자가 직접 들어가 함께 영상을 만들면서 새로운 추억을 남기는 기능입니다. Shop 에서는 모티프 영상을 개별로 구매하거나 모티프 패스를 구매할 수 있고, 모티프 탭에서는 현재 사용할 수 있는 영상을, 보관함에서는 지금까지 만든 모티프 영상을 확인하고 대표 모티프로 설정할 수 있습니다. 유료 서비스로 기획했기 때문에 토스페이먼츠 테스트 결제 환경으로 실제 결제 흐름도 구현했으며, 결제가 완료되면 이용 권한이 바로 반영됩니다."

## 9. 모티프 촬영 — 구미 아티스트 (핵심 ①·③)

멘트 포인트: "모티프 촬영 역시 챌린지 촬영과 비슷하게 동작합니다. 실시간 합성 화면을 보면서 위치를 맞추고, 5초 카운트다운 이후 원테이크로 촬영합니다. 촬영이 끝나면 서버에서 최종 영상을 합성하고, 완성된 영상은 보관함에 저장할 수 있습니다. 챌린지가 다른 사용자들과 함께 공유하고 참여하는 콘텐츠라면, 모티프는 좋아하는 아티스트와 나만의 추억을 만들고 개인적으로 보관하는 콘텐츠입니다. 이상으로 MOTIF 시연을 마치겠습니다."

| 상황 | 대응 |

## 부록. 발표 대본 전문

지금부터 MOTIF 시연을 시작하겠습니다.

먼저 로그인입니다. MOTIF 는 구글 로그인을 통해 간편하게 로그인할 수 있습니다. 최초 로그인 시에는 앱을 시작하기 전에 관심 있는 아티스트를 한 명 이상 선택해 구독하고, 닉네임을 설정한 뒤 서비스에 진입하게 됩니다.

먼저 홈 화면입니다. 홈 상단에서는 현재 사용자들이 참여한 챌린지 중 인기 있는 영상들을 바로 확인할 수 있습니다. 그 아래에는 Who's On 이라는 챌린지 랭킹이 있습니다. 아티스트별로 어떤 챌린지가 현재 인기를 얻고 있는지 확인할 수 있고, 전체보기를 누르면 전체 랭킹도 확인할 수 있습니다. 그리고 아래로 내려가면 사용자가 구독한 아티스트들의 최신 활동을 확인할 수 있습니다. 아티스트가 새롭게 올린 공지사항이나 새로운 모티프 영상이 하나의 피드로 제공됩니다.

다음은 챌린지 탭입니다. 챌린지 탭에서는 아티스트들이 올린 챌린지 영상을 숏폼 형태로 탐색할 수 있습니다. 영상에 좋아요를 누르거나 댓글을 남기면서 다른 사용자들과 소통할 수 있고, 챌린지에 대한 상세 정보와 함께 해당 챌린지에 참여한 다른 사용자들의 영상도 확인할 수 있습니다. 그리고 마음에 드는 챌린지를 발견했다면, 이 화면에서 바로 챌린지에 참여할 수 있습니다. 한번 직접 참여해보겠습니다.

챌린지 촬영 화면에 진입하면 먼저 아티스트와 함께 촬영할 사용자의 위치를 선택합니다. 촬영을 시작하면 사용자가 준비할 수 있도록 5초의 카운트다운이 진행됩니다. 이때부터 온디바이스에서 사용자의 영역을 실시간으로 분리해 아티스트 영상 위에 합성해주기 때문에, 사용자는 자신이 실제 영상 안에 들어가 있는 모습을 보면서 위치와 동작을 맞출 수 있습니다. 카운트다운이 끝나면 아티스트의 원본 영상과 사용자 촬영이 동시에 시작되고, 원본 영상이 끝날 때까지 원테이크 방식으로 촬영됩니다.

촬영이 끝나면 사용자 촬영 원본을 서버로 전달합니다. 서버에서는 앞서 발표에서 설명드린 AI 기술을 활용해 색감과 조명, 춤 동작 등을 보정하고 최종 영상을 합성합니다. 합성은 비동기로 진행되며, 작업이 완료되면 FCM 알림을 통해 사용자에게 알려줍니다. 사용자는 완성된 영상을 확인한 뒤 간단한 소개글과 함께 공개·비공개 여부, 댓글 허용 여부를 설정해서 업로드할 수 있습니다. 업로드가 완료되면 최종적으로 챌린지 참여가 완료됩니다.

다음은 마이페이지입니다. 마이페이지에서는 지금까지 직접 참여하고 업로드한 챌린지들을 확인할 수 있습니다. 또한 현재 구독 중인 아티스트를 확인할 수 있고, 아티스트별로 구독 정보와 챌린지, 모티프와 관련된 정보들도 확인할 수 있습니다. 그 다음 좋아요를 누른 영상이나 작성한 댓글과 같은 서비스 내 활동들도 다시 확인할 수 있습니다.

다음은 아티스트 상세 페이지입니다. 아티스트의 기본 정보와 구독 상태를 확인할 수 있고, 해당 아티스트가 올린 챌린지 영상과 공지사항을 한곳에서 확인할 수 있습니다.

다음은 MOTIF 의 또 다른 핵심 기능인 모티프 탭입니다. 모티프는 쉽게 말하면 인생네컷의 영상 버전이라고 생각하시면 됩니다. 아티스트가 제공하는 짧은 영상 속에 사용자가 직접 들어가 함께 영상을 만들면서, 좋아하는 아티스트와 새로운 추억을 남길 수 있도록 만든 기능입니다. 먼저 Shop 에서는 아티스트가 제공하는 모티프 영상을 개별로 구매하거나, 모티프 패스를 구매할 수 있습니다. 개별 구매한 영상은 계속 사용할 수 있고, 모티프 패스를 이용하면 이용 기간 동안 해당 아티스트의 일반 모티프 영상들을 자유롭게 사용할 수 있습니다. 모티프 탭에서는 이렇게 구매했거나 패스를 통해 현재 사용할 수 있는 영상들을 모아서 보여줍니다. 그리고 보관함에서는 지금까지 아티스트와 함께 만든 모티프 영상들을 다시 확인할 수 있습니다. 이 중 하나를 대표 모티프로 설정할 수도 있습니다.

MOTIF 의 모티프 기능은 유료 서비스로 기획했기 때문에 실제 결제 흐름도 구현했습니다. 결제는 토스페이먼츠 테스트 결제 환경을 이용하고 있으며, 개별 모티프 영상이나 모티프 패스를 선택하면 토스페이먼츠 결제 화면으로 연결됩니다. 결제가 완료되면 이용 권한이 바로 반영되고, 해당 아티스트와 바로 모티프 영상을 만들 수 있습니다.

그럼 마지막으로, 구미 아티스트와 직접 모티프 촬영을 진행해보겠습니다. 모티프 촬영 역시 앞에서 보여드린 챌린지 촬영과 비슷하게 동작합니다. 사용자는 실시간 합성 화면을 보면서 아티스트와 자신의 위치를 맞추고, 5초의 카운트다운 이후 원테이크 방식으로 촬영합니다. 촬영이 끝나면 서버에서 최종 영상을 합성하고, 완성된 영상은 보관함에 저장할 수 있습니다. 챌린지와 가장 큰 차이점은, 챌린지가 다른 사용자들과 함께 공유하고 참여하는 콘텐츠라면 모티프는 좋아하는 아티스트와 나만의 추억을 만들고 개인적으로 보관하는 콘텐츠라는 점입니다.

이상으로 MOTIF 시연을 마치겠습니다.

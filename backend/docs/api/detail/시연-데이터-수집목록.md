# 시연 데이터 수집 목록 — 에스파 · 블랙핑크 · 프로미스나인 · NMIXX

스키마(`db/changelog/sql/`)와 어드민 명세 v0.5 §1.4 에서 뽑은 **실제 필요 항목**이다.
컬럼에 없는 것은 모으지 않는다 — 데뷔일·팬덤명·SNS 링크 같은 건 저장할 자리가 없다.

## 등록 순서 (FK 제약)

```
소속사 → 그룹 → 아티스트(users+artists) → 곡 → 챌린지 → 에셋 → 공지 → 배너
```

앞 단계가 없으면 뒤가 막힌다. 수집도 이 순서로 채우는 게 안전하다.

## 3. 아티스트 — 23명 (여기가 제일 큰 덩어리)

`users(role='ARTIST')` 와 `artists` 두 테이블에 한 트랜잭션으로 들어간다.

| 필요 | 컬럼 | 제약 | 필수 |
|---|---|---|---|
| 이름 | `users.nickname` | 1~50자 | ✅ |
| 소속사 | `artists.company_seq` | **그룹 소속사와 일치해야 함** | ✅ |
| 그룹 | `artists.group_seq` | NULL 이면 솔로 | — |
| 소개글 | `artists.bio` | TEXT, 길이 제한 없음 | — |
| 프로필 사진 | `users.profile_image_key` | `profiles/{uuid}.jpg` | — |
| 모티프 배경 | `artists.motif_bg_image_key` | `artists/{uuid}.jpg` | — |

**이미지 규격 (§1.4 · `admin.media.image`)**

- 형식: `image/jpeg` · `image/png` · `image/webp`
- 크기: **≤10MB**
- 해상도 제약 **없음**

**멤버 수**

| 그룹 | 인원 |
|---|---|
| 에스파 | 4 |
| 블랙핑크 | 4 |
| 프로미스나인 | 9 |
| NMIXX | 6 |
| **합계** | **23** |

→ 이름 23개 · 프로필 23장 · 배경 23장 = **이미지 최대 46장**

배경 이미지는 모티프 촬영 화면 배경이라 **인물 사진이 아니어도 된다**. 없으면 NULL 로 두고 나중에 채워도 등록은 된다.

## 5. 챌린지 — 영상 작업이 가장 오래 걸린다

| 필요 | 제약 |
|---|---|
| 원본 영상 | `video/mp4` 또는 `video/quicktime`, **≤300MB** |
| 방향 | **세로 (height > width)** — 위반 시 400 `MEDIA_INVALID` |
| 길이 | **≤60초** |
| 곡 | 위 `songs` 중 하나 |
| 메인 아티스트 | 23명 중 하나 |
| 슬롯 참여자 | 메인 아티스트도 슬롯 가능, 중복 불가 |
| 슬롯별 앵커 | 썸네일 대비 0~1 비율 `x`·`y`·`r` (어드민 화면에서 클릭해 찍는다) |

**편집본은 슬롯당 1개다** *(2026-09-21 — 조합 폐기)*. 사용자가 고르는 것이 함께할
아티스트 한 명이라 2명 이상을 동시에 지운 영상은 쓰지 않는다.

| 슬롯 n | 편집본 수 | (참고) 2026-09-21 이전 |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 2 | 3 |
| 3 | 3 | 7 |
| 4 | 4 | 15 |

편집본 각각: 영상(길이 = 원본 ±500ms) + 첫 장면 jpg (+ 선택 화면 jpg, 생략 가능).
**AI 팀 산출물**(S15P21D104-565·566·567).

**S3 위치는 `private/edited/{challengeSeq}/{challengeParticipantSeq}/…` 다**
*(2026-09-22 — 구 `private/edited/{challengeSeq}/…`, 그 전엔 `edited/…`)*.
`private/` 인 것은 앱이 편집본을 직접 받아 서명이 필요해졌기 때문이고, 슬롯까지
내려간 것은 챌린지 하나에 슬롯이 여럿이라 한 폴더에 섞이면 구분이 안 되기 때문이다.

**슬롯 번호는 챌린지를 등록해야 난다.** 그래서 순서가 `챌린지 등록 → 슬롯 번호 확인 →
편집본 업로드` 다 — 등록 화면에는 편집본 칸이 없다.

> **전부 갖출 필요는 없다.** 편집본이 빈 슬롯은 앱에서 잠기고(§7.5 `initialSceneUrl: null`)
> 나머지 슬롯은 정상 동작한다 — 시연은 **슬롯 2명 중 1명만** 채워도 돈다.

## 6. 모티프 에셋 `motif_assets`

| 필요 | 제약 |
|---|---|
| 제목 | ≤100자 |
| 설명 | TEXT, 선택 |
| 영상 | mp4/mov, ≤300MB, **가로 (width > height)**, **≤20초** |
| 아티스트 | 23명 중 하나 |
| 가격 | KR 기준 `NUMERIC(10,2)`, > 0, 통화 `KRW` |

챌린지와 **방향이 반대다**(에셋은 가로). 썸네일은 app-media 가 만들므로 수집 불필요.

## 9. 패스 가격 `motif_pass_prices`

아티스트 × 국가 × 개월 조합마다 금액. 시연은 아티스트당 1·3·12개월 정도면 충분하다.

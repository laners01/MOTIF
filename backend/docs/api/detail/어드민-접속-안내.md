# 어드민 접속 안내 (2026-09-13)

운영 서버에 어드민이 올라갔다. **테일넷에서만 열린다.**

---

## 1. 접속 준비 — 두 가지

### ① Tailscale 로 팀 테일넷에 조인

안 되어 있으면 아래 hosts 를 고쳐도 서버에 닿지 않는다.

### ② hosts 에 한 줄 추가

`j15d104.p.ssafy.io` 는 공개 DNS 가 **공인 IP** 를 준다. 그쪽으로 가면 어드민이
404 다(의도된 동작 — 아래 §4). 호스트명은 그대로 두고 주소만 테일넷으로 돌린다.

**mac / 리눅스**

```bash
echo "100.106.64.43  j15d104.p.ssafy.io" | sudo tee -a /etc/hosts
```

**윈도우** — 관리자 권한 메모장으로 `C:\Windows\System32\drivers\etc\hosts` 열고

```
100.106.64.43  j15d104.p.ssafy.io
```

되돌릴 때 (mac)

```bash
sudo sed -i '' '/100.106.64.43[[:space:]]*j15d104.p.ssafy.io/d' /etc/hosts
```

> **왜 hosts 인가** — Tailscale 은 임의 DNS 레코드를 추가할 수 없다("It's not possible
> to add arbitrary records to MagicDNS"). `*.ts.net` 인증서를 쓰는 방법도 있지만
> 90일마다 수동 갱신이 필요해 프로젝트 기간에 비해 부채가 크다. 한 줄이 제일 싸다.

## 2. 접속

```
https://j15d104.p.ssafy.io/admin/login
```

| | |
|---|---|
| 아이디 | `admin` |
| 비밀번호 | 팀 비밀 저장소 참조 (김상현) |

로그인하면 `/admin/challenges/new` 로 이동한다.

404 가 그대로면 브라우저 캐시다 — 시크릿 창이나 강력 새로고침(⌘⇧R).

## 3. ⚠️ 안드로이드 파트 주의

이 hosts 줄이 있는 동안 **`/api/**` 도 테일넷을 탄다.** 앱 연동을 테스트할 때는
줄을 빼야 실제 사용자 경로(공인망)와 같은 조건이 된다. 어드민 볼 때만 넣어라.

## 4. 지금 되는 것 / 안 되는 것

### 화면

| 경로 | 상태 |
|---|---|
| `/admin/login` | ✅ |
| `/admin/challenges/new` | ✅ 화면은 뜨지만 **데이터가 없어 select 가 비어 있다** |
| `/admin/prices` | ✅ 동일 |
| `/admin/notices` | ✅ 동일 |
| 소속사·그룹·아티스트 관리 화면 | ❌ 미구현 (S15P21D104-387·388) |
| 챌린지 목록·에셋 목록 화면 | ❌ 미구현 (395·401) |

### API — 목록 조회가 전부 열렸다

`songs` · `artists` · `notices` · `challenges` · `motif-assets` 전부 200.
**DB 가 비어 있어 0건일 뿐이다.** 데이터를 넣으면 화면이 바로 채워진다.

### 공인망에서 404 가 나는 것은 정상이다

어드민 경로는 허용 대역(테일넷) 밖에서 **403 이 아니라 404** 를 낸다. 403 은
"경로는 있는데 못 들어온다"를 알려줘 어드민 화면의 존재를 드러내기 때문이다
(어드민 명세 §1.1). `/api/health` 같은 서비스 API 는 공인망에서도 정상이다.

## 5. 지금 필요한 것 — 시연 데이터

화면은 다 떴는데 **DB 가 비어서 아무것도 안 보인다.** 아래 순서로 넣어야 한다.

```
소속사 → 그룹 → 아티스트 → 곡 → 챌린지
```

앞 단계가 없으면 뒤가 막힌다. 1순위는 **텍스트 전량**이다 — 스프레드시트 한 장이면
되고, 지금 바로 만들 수 있다.

| | 필요한 것 |
|---|---|
| 소속사 4 | 회사명만 |
| 그룹 4 | 그룹명 + 소속사 |
| 아티스트 23 | 이름 · (선택) 소개글 · 프로필 사진 |
| 곡 | 제목 + 가수명만 |

상세 규격(이미지 크기·영상 방향·길이 제한)은 같은 폴더의
**`시연-데이터-수집목록.md`** 에 있다. 영상은 제약이 있으니 그것부터 확인할 것:

- 챌린지 원본 — **세로**(h>w), **≤60초**, mp4/mov, ≤300MB
- 모티프 에셋 — **가로**(w>h), **≤20초**

## 6. 안 되면

- `/admin/login` 이 404 → Tailscale 연결 확인 → hosts 줄 확인 → 캐시
- 인증서 경고 → hosts 에 **IP 가 아니라 호스트명** 으로 넣었는지 확인
- 로그인 실패 → 아이디는 `admin`, 비밀번호는 팀 비밀 저장소

그래도 안 되면 김상현.

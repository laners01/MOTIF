# ADR-0003. 로컬 개발 환경 — 격리·하이브리드·서버 3모드

- 상태: 승인
- 일자: 2026-09-02
- 관련: MODERA 회고(local-infra), Tailscale 구성(인프라 구축현황)

## 컨텍스트

과거 프로젝트에서 반복된 고통 세 가지: ① 모노레포에서 한 파트가 미완이면
다른 파트 개발이 막힌다 ② AI 서버를 로컬에서 연동해볼 수 없다 ③ 로컬 앱과
실서버 구성 요소를 섞어 테스트할 수 없다. 원인은 대부분 "원격 내부 서비스에
로컬이 닿을 수 없다"(방화벽, 유동 IP, 터널)였다.

MOTIF에서는 팀원 노트북이 전부 테일넷 멤버다 — 로컬 프로세스가
`100.106.64.43`의 MQ·DB를 터널 없이 직접 부를 수 있다.

## 결정

Spring 프로파일로 3모드를 표준화한다.

| 모드 | 프로파일 | DB | MQ·Redis | 용도 |
|---|---|---|---|---|
| 격리 | `local` | compose | compose | 기본. 스키마 실험·기능 개발 |
| 하이브리드 | `local-remote` | compose(자기 것) | 서버(테일넷) | 파이프라인 통합 확인 |
| 서버 | `prod` | 클러스터 | 클러스터 | k8s 배포 |

- `backend/local-infra/docker-compose.yml` 한 번으로 PG(스키마·계정·권한
  동일) + RabbitMQ(운영과 동일 토폴로지) + Redis + **스텁 GPU 워커**가 뜬다.
- 스텁 워커는 `job.composite`를 소비해 수 초 뒤 `composite.done`을 발행하는
  가짜 합성기다. 오프라인에서도 발행→소비→완료 전 파이프라인이 돈다.
- 전환은 프로파일 + `.env`뿐이다. 접속 정보는 전부 `${...}` 참조라 코드
  변경이 없다.
- S3는 LocalStack 대신 **실버킷의 `dev/` 프리픽스**를 쓴다. presigned 동작이
  운영과 동일한 것이 모의보다 가치가 크다.

## 과거 고통과의 대응

1. 파트 미완 → 큐가 시간을 분리한다. 소비자가 없어도 발행하며 개발하고,
   생산자가 없어도 `rabbitmqadmin publish`로 이벤트를 주입해 개발한다.
   계약은 module-event가 고정한다.
2. AI 로컬 연동 → 하이브리드 모드에서 로컬 앱이 서버 MQ에 잡을 발행하면
   서버 쪽 (스텁) GPU 워커가 실제로 처리한다. 오프라인이면 compose 스텁.
3. 혼합 테스트 → 하이브리드 모드가 정확히 그 형태다.

## 규칙 (하이브리드 모드의 함정)

**서버 큐를 구독하는 컨슈머를 로컬에서 띄우지 않는다.** 같은 큐를 여럿이
물면 라운드로빈으로 메시지를 뺏어가, 서버 알림 서비스가 받을 이벤트를
로컬이 삼킨다. 이를 코드로 강제한다: `local-remote` 프로파일에서
app-notification은 `listener auto-startup=false`. 컨슈머까지 통합해야 하면
개인 vhost(`/motif-dev-<이름>`)를 만들어 쓴다.

## 검토한 대안

- **서버 DB 공용** — 셋업은 0이지만 Liquibase 마이그레이션이 경합하고, 한
  명의 실험 데이터가 전원에게 보인다. 기각.
- **LocalStack(S3 모의)** — presigned·CORS 동작이 실물과 미묘하게 달라
  "로컬에선 됐는데" 류의 함정을 만든다. 실버킷 프리픽스로 대체.

## 결과

- 전제: 팀원 전원 Docker 설치 + Tailscale 조인.
- 로컬 compose의 자격증명은 로컬 전용 값(비밀 아님)으로 고정하고, 서버
  자격증명은 `.env`(gitignore)로만 주입한다.

MOTIF 구글 로그인 테스트

실제 구글 ID 토큰을 받아 POST /api/v1/auth/login/google(명세 §2.1)을 확인하는 도구다. core-api 가 자기 정적 리소스로 서빙하므로 API 와 같은 출처다 — CORS 가 필요 없고, 로컬과 배포 서버에서 똑같이 동작한다.

1. 여는 곳

로컬   http://localhost:8081/api/dev/login-test.html   (앱을 8081 에 띄운 뒤)
서버   https://j15d104.p.ssafy.io/api/dev/login-test.html

Google Cloud Console > 사용자 인증 정보 > 웹 애플리케이션 클라이언트의 승인된 JavaScript 원본에 여는 주소의 출처를 등록해야 한다 — http://localhost:8081, https://j15d104.p.ssafy.io. 없으면 구글이 origin_mismatch로 거부한다.

2. 웹 클라이언트 ID

웹 클라이언트 ID여야 한다. Android 클라이언트 ID를 넣으면 발급되는 토큰의 aud가 서버 설정과 어긋나 401 INVALID_GOOGLE_TOKEN이 된다. 서버의 GOOGLE_CLIENT_ID와 같은 값을 써야 한다.

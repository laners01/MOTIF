#아티스트xy반지름

슬롯 행을 클릭해 지정한 뒤 위 프레임을 클릭하면 프로필 원이 그 자리에 앉는다. 값은 썸네일 대비 0~1 비율이다 — 시안(402 폭·지름 80)의 반지름이 기본값 0.0995.

MOTIF 구글 로그인 테스트

실제 구글 ID 토큰을 받아 POST /api/v1/auth/login/google(명세 §2.1)을 확인하는 로컬 도구다. file://로 열면 동작하지 않는다 — 아래 절차대로 서버로 띄워서 열어야 한다.

1. 준비

cd backend/local-infra && python3 -m http.server 5500
# 브라우저에서 http://localhost:5500/google-login-test.html

Google Cloud Console > 사용자 인증 정보 > 웹 애플리케이션 클라이언트의 승인된 JavaScript 원본에 http://localhost:5500을 추가해야 한다. 없으면 구글이 origin_mismatch로 거부한다.

2. 웹 클라이언트 ID

웹 클라이언트 ID여야 한다. Android 클라이언트 ID를 넣으면 발급되는 토큰의 aud가 서버 설정과 어긋나 401 INVALID_GOOGLE_TOKEN이 된다. 서버의 GOOGLE_CLIENT_ID와 같은 값을 써야 한다.

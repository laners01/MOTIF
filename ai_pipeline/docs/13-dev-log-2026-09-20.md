## 2. Job 실행 계약 (payload env) — 중요

실서비스에서는 `intake.py`(CPU 서비스)가 요청을 받아 두 Job을 launch한다:

| Job | 엔트리포인트 | payload env | 기타 필수 env |
|---|---|---|---|
| precompute | `python -m run_final_cloud_run_job.precompute_worker` | **`MOTIF_PRECOMPUTE`** (JSON) | `MOTIF_REQUEST_ID`(선택) |
| compose | `python -m run_final_cloud_run_job.worker` | **`MOTIF_JOB`** (JSON) | `MOTIF_REQUEST_ID`(필수), `MOTIF_CALLBACK_BASE`, `MOTIF_WORKER_TOKEN` |

> ⚠️ 함정: precompute는 `MOTIF_JOB`이 아니라 **`MOTIF_PRECOMPUTE`**다. (이 세션에서 한 번 혼동해 실행 하나를 날림.)

`validate_single_task()`가 `CLOUD_RUN_TASK_COUNT=1`, `CLOUD_RUN_TASK_INDEX=0`을 요구한다.

## 6. 다음 할 일 (우선순위)

1. **p4ssv 결과 확인** → full_load SVOR 실측, light·portable export→S3 검증.
2. **2명 이상 배경으로 compose 전체 검증.** 현재 `m1.mp4`는 1명이라 compose가 `len(people)<2`로 거부됨(`service.py:_choose_people`). precompute는 인물마다 "그 인물 제거 배경 + 관절/기하/조명 세트"를 만들므로 2명이면 2세트 생성됨.
3. **task-timeout 3600s(GPU 한도) 내 2명 배경 완주 가능한지 판단** — full_load SVOR 실측치로 추정(SVOR ×2 + 나머지).
4. backend: S3 `precomputed/*` GET+PUT IAM (`docs/06-backend-handoff-2026-09-20.md`).
5. (선택) 이미지 축소: `-devel`→runtime 베이스(멀티스테이지, ~-3GB). wheel 있으면 nvcc 불필요.

## 7. 재현 명령

```bash
# 빌드 (캐시 config — 코드만 바뀌면 빠름; :cache 없으면 첫 빌드는 풀빌드)
gcloud builds submit --config=cloudbuild.yaml --substitutions=_TAG=v8 --project=ssafy-motif .

# job 이미지/타임아웃 갱신 (GPU는 task-timeout 최대 3600)
gcloud run jobs update motif-precompute-job \
  --image=us-central1-docker.pkg.dev/ssafy-motif/video-workers/motif-compose:v8 \
  --task-timeout=3600 --region=us-central1 --project=ssafy-motif

# precompute 수동 실행 (payload는 MOTIF_PRECOMPUTE, JSON 콤마 회피 위해 ^@^ 구분자)
gcloud run jobs execute motif-precompute-job --region=us-central1 --project=ssafy-motif --async \
  --update-env-vars='^@^MOTIF_PRECOMPUTE={"job_uuid":"precompute-v8-1","attempt":1,"base_video_key":"edited/<...>.mp4","source_video_key":null}@MOTIF_REQUEST_ID=precompute-v8-1'
```

## 8. 알려진 이슈/함정

- **payload env**: precompute=`MOTIF_PRECOMPUTE`, compose=`MOTIF_JOB`(§2). 헷갈리면 즉시 크래시.
- **GPU task-timeout 최대 3600초(1시간)**. cpu_offload로는 SVOR 1인물이 34분+라 timeout에 걸렸음 → full_load 필수.
- **SVOR full_load OOM 미검증**: 96GB라 안전 예상이나, OOM 시 `prepost.py`의 SVOR 호출 `memory_mode`를 `model_cpu_offload`로 복귀.
- **배경 최소 2명**: compose 성립 조건. 1명 배경은 precompute만 되고 compose 불가.
- **빌드**: `gcloud builds submit --tag`는 `--no-cache` 강제 → 반드시 `--config=cloudbuild.yaml` 사용.
- **RF-DETR TensorRT 로그**: `No module named 'inference_models'`로 PyTorch CUDA fallback은 **정상**(TensorRT는 선택적 가속). 정확도 동일.
- **wheel**: `docker/wheels/pytorch3d-*.whl`가 git에 없음 → 빌드 전 GCS에서 받거나 `cloudbuild.pytorch3d.yaml`로 생성(§3).
